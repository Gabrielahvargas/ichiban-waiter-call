# Publicar el arreglo de las dos luces SERVER

- Publico la app para que la TV, los botones de las mesas y el panel de botones reciban dos arreglos:
  - Las dos luces SERVER se ponen rojas cuando hay una llamada y vuelven a blanco cuando la atienden.
  - Ya no sale por error el aviso "Necesitas acceso de administrador" al cambiar de menú.
- Al terminar te paso el link de la app publicada.
- Prueba sugerida: aprieta el botón de llamar en una mesa. Las dos luces SERVER deben ponerse rojas. Después aprieta el botón verde: deben volver a blanco.
- En la TV, recarga la pantalla de llamadas para que tome la versión nueva.
- Con la publicación también llegan otros cambios que estaban solo en la vista previa: el reloj en la pantalla de llamadas y el ranking de ventas.
